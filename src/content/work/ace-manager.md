## Overview

As a Software Developer at Ace IOT Solutions, I spearheaded the development and enhancement of the **Ace Manager** web application — a central platform for managing IoT data across client facilities.

## Key Contributions

### Data Processing & Export
- Integrated advanced data processing features for Excel file uploads
- Facilitated diverse data export capabilities (JSON, CSV)
- Designed and implemented robust backend API features for PostgreSQL database interactions

### Volttron Platform
- Configured the Volttron Platform to optimize data collection processes at client facilities
- Created data collection agents within Volttron, including the YOLO agent — a machine learning-based tool for analyzing security camera images to count people and objects

### Testing & Security
- Developed a comprehensive testing framework using pytest, ensuring application security and protection against unauthorized access

### Graph Database Architecture
- Collaborated with a client to architect a new graph database ontology using Neo4J for Smart Building data management

## Tech Stack

- **Backend:** Python, Flask, PostgreSQL, Neo4J
- **Frontend:** JavaScript, HTML, CSS
- **Platform:** Linux Volttron
- **Tools:** Git, pytest
