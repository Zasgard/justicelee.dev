## Overview

During my time at Trew, I contributed to multiple enterprise-level warehouse automation systems, working across both hardware control and software layers.

## HMI Software — CHAMP

The CHAMP (Custom Human Machine Interface) software is Trew's proprietary HMI system used at client warehouse facilities across the country. My contributions included:

- Modified and reviewed the in-house HMI software using **C#**, **C++**, **JavaScript**, **HTML**, **CSS**, **Python**, and **JSON**
- Reviewed and modified electrical schematics to support clients both on-site and off-site
- Developed and added new functionality to PLCs using **ladder logic**

## SmartMoves WES

SmartMoves is Trew's warehouse execution system (WES), which coordinates the movement of goods through automated warehouse systems.

- Contributed to the system by modifying **C# code** and **SQL databases**
- Provided on-site support, monitoring and fixing code bugs
- Delivered customer support on-site and off-site, troubleshooting and resolving issues

## Tech Stack

- **Languages:** C#, C++, JavaScript, HTML, CSS, Python, SQL
- **Systems:** PLC Ladder Logic, HMI Software, Warehouse Execution Systems
- **Tools:** Git, SQL Server
